# Finance Graphs

A banking statement visualization tool built with Astro, Tailwind CSS v4, and Vue 3.

## Features (Planned)

- Upload CSV files (banking statements)
- Parse and display transactions in a sortable list
- Group transactions into categories
- Visualize financial data with interactive graphs

## Tech Stack

- **Astro** - Static site generator
- **Vue 3** - UI components
- **Tailwind CSS v4** - Styling

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
